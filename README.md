# WordPress Admin Panel Config – Структура для генерації інтерфейсу

Цей конфігураційний файл використовується для **автоматичного створення адміністративної панелі в WordPress**. Його можна адаптувати під проєкти будь-якої складності — від простого додавання одного поля до повноцінного модульного розширення з CPT, AJAX, SMTP, кастомними скриптами та стилями.

---

## 🧠 Основна логіка

Генератор читає JSON-файл, де описано:

- які поля потрібні в адмін-панелі (input, checkbox, картинки тощо),
- які типи записів або сторінок використовуються (`post`, `option`, `request`),
- які шляхи для збереження коду (`inc`, `css`, `js`),
- чи вмикати режим розробки, створювати шаблонні функції, чи підключати `wp_enqueue_media`.

---

## 📂 Основна структура

### `"main"`
Базова інформація:
- `word` — унікальне ключове слово, яке буде префіксом для функцій і файлів.
- `type` — тип генерації (наприклад, `option` для сторінки налаштувань).
- `main_path` — абсолютний шлях до теми WordPress.
- `main_file` — файл, у який вбудовується підключення функціоналу (часто `functions.php`).

### `"path"`
Визначає структуру проєкту:
- `inc` — папка для PHP-логіки.
- `js` — папка для скриптів, пов’язаних з полями.
- `css` — стилі для адмінки.

---

## 🧩 Типи (секція `"types"`)

Налаштування кожного типу використання:

- **`post`** — додає мета-блок до постів (Custom Fields).
- **`option`** — створює окрему сторінку з налаштуваннями в адмінці.
- **`request`** — додає форму з надсиланням email через `PHPMailer`.

Всередині кожного:
- `input`, `checkbox`, `img_link`, `img_svg` — типи полів.
- `hl_mixed` — блоки з кількома полями одразу (наприклад, картинка + посилання).
- `points`, `table` — специфічні компоненти для генерації табличних/точкових структур.

---

## ⚙️ `"global"`

Загальні налаштування:
- `debug_on` — виводити службові повідомлення.
- `include_in_func` — чи підключати автогенерацію через `functions.php`.
- `enqueue_media_uploader_wp` — чи підключати завантажувач зображень WordPress.
- `create_folder` — створювати потрібні директорії.
- `auto_name_label` — генерувати назви полів автоматично.
- `create_with_label` — створювати поля з мітками (labels) за замовчуванням.

---

## 🛠 `"dev_mod"`

Режим розробки:
- `rewrite` — перезаписувати вже існуючі файли без підтвердження.

---

## 🔐 `"secret_data"`

Секретні налаштування:
- Використовуються для конфігурації SMTP (наприклад, Gmail), якщо в `request` потрібно відправляти листи.

---

## 💡 Призначення

Ця система створена для **швидкої генерації кастомних адміністративних панелей WordPress**, яка:

- допомагає уникнути рутини при написанні однотипного коду,
- автоматизує створення файлів і директорій,
- дозволяє конфігурувати все з одного JSON-файлу.

Підходить як для фріланс-проєктів, так і для внутрішніх CMS-інструментів.

---
